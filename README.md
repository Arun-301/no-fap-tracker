# 365-Day NoFap Journey Masterclass 💪

Hey everyone! 👋

This is my personal project, built to help me stay disciplined, track my daily habits, and work towards my 365-day goal.

I wanted something more than a simple habit tracker, so I built a dashboard where I can check my progress, earn achievements, complete daily missions, and keep track of my journey.

## What can you do with it?

- **Dashboard:** See your current streak, journey progress, and upcoming milestones.
- **Daily Check-In:** Track meditation, workouts, deep work, and other daily habits.
- **Calendar:** View previous days, update old entries, and keep future dates locked.
- **Achievements:** Unlock badges at different milestones, from Day 1 all the way to Day 365.
- **XP System:** Earn experience points and level up as you complete activities.
- **Daily Missions:** Give yourself small goals to complete every day.
- **Analytics:** Check your progress and see how consistently you've been following your routine.
- **Relapse Tracker:** Record triggers, understand what went wrong, and plan how to handle things better next time.
- **Emergency Mode:** Use breathing exercises and other activities when you're dealing with strong urges.
- **Daily Journal:** Write about your wins, struggles, and lessons learned.
- **Themes:** Switch between dark and light mode.
- **Backup & Restore:** Export your data and restore it later.

## Built With

- HTML
- CSS
- JavaScript
- IndexedDB

The project runs directly in your browser, so you don't need to set up a backend or connect a database server.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in Google Chrome.
3. Enter the PIN: `2468`.
4. Set your journey start date in Settings.
5. Start tracking your progress!

## A Note About Privacy

The app stores its data locally in the browser using IndexedDB. Make regular backups so you don't lose your progress.

The PIN is only a basic lock screen. It does not encrypt your saved data, so don't treat it as strong security.

## Why I Made This

I'm building this project to make it easier to stay consistent, learn from mistakes, and focus on improving one day at a time.

The goal isn't to be perfect every single day. It's to keep showing up, understand your habits, and get better over time.
